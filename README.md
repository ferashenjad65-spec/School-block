# School-Block

Ein kleines, touchfreundliches Block-Puzzle für den Browser. Die Oberfläche ist auf Deutsch und funktioniert auf Smartphone, Tablet und Desktop.

## Lokal starten

`index.html` im Browser öffnen.

## Veröffentlichung mit GitHub Pages

1. Im Repository **Settings** öffnen.
2. Links **Pages** auswählen.
3. Unter **Build and deployment** die Quelle **Deploy from a branch** wählen.
4. Branch **main** und Ordner **/(root)** auswählen, dann **Save**.
5. Nach dem Build erscheint die öffentliche Website-Adresse im Bereich Pages.

## Aktueller Funktionsumfang

- 8×8-Spielfeld und drei zufällige Formen
- Reihen und Spalten löschen
- Punkte, Linien und persönlicher Rekord
- Lokale Bestenliste und Speicherung im Browser

Hinweis: Klassenbeitritt, gemeinsame Online-Bestenliste und Admin-Verwaltung sind noch nicht aktiviert. Die aktuelle Version speichert Ergebnisse nur lokal auf dem jeweiligen Gerät.
